# Passé composé

> [!info] Structure générale  
> **SUJET + AUXILIAIRE ([[avoir]] / [[être]]) + PARTICIPE PASSÉ**

Exemples :
- _J’ai mangé au restaurant hier._
- _Elle est arrivée à 8h._
- _Nous avons fini le travail._

## Quel auxiliaire utiliser ?

## A. **Verbes avec “[[avoir]]”** (la majorité)

> [!note] Rappel  
> La plupart des verbes utilisent **[[avoir]]** comme auxiliaire.

### Exemples fréquents

| Infinitif | Participe passé | Traduction |
| --------- | --------------- | ---------- |
| parler    | parlé           | hablar     |
| finir     | fini            | terminar   |
| prendre   | pris            | tomar      |
| voir      | vu              | ver        |
| mettre    | mis             | poner      |
| choisir   | choisi          | elegir     |
| faire     | fait            | hacer      |
| manger    | mangé           | comer      |
| attendre  | attendu         | esperar    |

## **Verbes avec “[[être]]”**

> [!tip] Astuce importante  
> Avec **être**, le participe passé s’accorde avec le sujet :  
> _elle est allée_, _ils sont arrivés_, _elles sont montées_…

## C. **Verbes [[pronominaux]]**

> [!info]  
> Toujours avec **être**, + accord si nécessaire.

Exemples :

- _Je **me suis** levé(e)._
- _Elle **s’est** préparée._
- _Nous **nous sommes** reposés._

# 3. La négation au passé composé

> [!warning] Structure  
> **ne + auxiliaire + pas + participe passé**

Exemples :

- _Je **n’ai pas** mangé._
- _Elle **n’est pas** venue._

---

# 4. Mots utiles pour raconter le passé

- _hier_
- _avant-hier_
- _la semaine dernière_
- _il y a + durée_
- _d’abord… ensuite… puis… enfin…_

---

# 5. Cas spéciaux : COD + changement d’auxiliaire

> [!note] COD = Complément d’Objet Direct  


Certains verbes changent d’auxiliaire selon la présence d’un COD.

### Exemples

| Verbe     | Avec COD → auxiliaire | Sans COD → auxiliaire |
| --------- | --------------------- | --------------------- |
| monter    | avoir                 | être                  |
| descendre | avoir                 | être                  |
| sortir    | avoir                 | être                  |
| passer    | avoir                 | être                  |
| retourner | avoir                 | être                  |
| rentrer   | avoir                 | être                  |
### Exemples :

- _Je suis descendu._
- _J’ai descendu **les valises**._ (COD)
